Suggested flow

Learning Path

Designed for developers and architects who already know HTTP, REST, basic C#, and Azure resource management.

Start With the Platform

Overview and architecture and tiers establish the runtime model. Complete APIM provisioning as prework.

Design and Publish a Contract

Study API design and import, then publish the .NET 10 and Function APIs in Labs 02-03.

Control and Observe Calls

Connect policies, security, and lifecycle and observability to successful and denied requests.

Enable Consumers and Govern the Portfolio

Build the developer experience in Lab 04 and register your inventory with API Center in Lab 05.

Extend to GenAI (Optional)

Apply the platform concepts to GenAI gateway design: token budgets, model routing, semantic caching, and privacy-aware telemetry. Allow about 20 additional minutes outside the guided schedule.

Plan ahead: four hours includes concepts, active lab work, a break, and cleanup, not tool installation or cloud provisioning waits. Complete the prework, use a disposable resource group, and review costs before deploying.
Go deeper: the topic modules include extended reference covering the primary presentation, with 14 original PowerPoint visuals. Explore SOAP and WebSockets, caching and validation, regions and zones, and automation, debugging, and events. Extended reading is additional to the four-hour core.
