Lab 05: Inventory APIs in API Center

Record the Catalog contract and its gateway deployment, then finish with verified cleanup.

Azure portalL300~25 min + final cleanup

Scenario and Objectives

Your organization needs to discover the Catalog API without knowing which APIM service hosts it. Register a small inventory record that points to the existing runtime rather than creating another proxy.

  • Create API Center using the Free plan.
  • Register an API version and the saved OpenAPI definition.
  • Associate a testing environment and the APIM deployment URL.
  • Verify inventory relationships and remove the disposable environment.
Related topic: API Center and API Governance.

Build

Step 1: Create API Center

  1. In the Azure portal, open Subscriptions and select the workshop subscription.
  2. Open Settings > Resource providers.
  3. Search for Microsoft.ApiCenter and select Register if it is not registered.
  4. Search for API Centers in the portal and select + Create.
  5. Select the existing dedicated group, your API Center name, and a supported region.
  6. Select Free for Pricing plan.
  7. Select Review + create, then Create.

Expected result: the API center is ready with the intended plan. The lab does not require Standard, synchronization, or an API Center portal deployment.

Learn more: Create API Center and plans and region availability.

Step 2: Register the API and Definition

  1. Open the API center > Inventory > Assets.
  2. Select + Register an asset > API.
  3. Enter Catalog API as API title and select REST for Asset type.
  4. Enter v1 for Version title and choose Testing for Version lifecycle.
  5. Add a short description using synthetic workshop information, then select Create.
  6. Open Catalog API and its Versions list, then open the existing v1 version.
  7. In its definitions area, add a definition titled Catalog OpenAPI, select OpenAPI, and use specification version 3.0.
  8. Upload the saved catalog.openapi.json through the File option and save/create the definition.

Expected result: one API contains version v1 with a downloadable OpenAPI definition. Do not create a second v1 just to attach a file. Some portal versions expose Select a specification directly in the version form; attach the same file there if that is the form presented.

Learn more: Register APIs, versions, and definitions. Portal wording can vary during UI updates; follow the API/version/definition hierarchy, not a duplicated version.

Step 3: Add Environment and Deployment Metadata

  1. Open Inventory > Environments > + New environment.
  2. Set Environment title to Workshop Testing and Environment type to Testing.
  3. Under Server, select Azure API Management as Type.
  4. Optionally record the published developer portal URL under onboarding; never include a subscription key.
  5. Select Create.
  6. Return to Inventory > Assets > Catalog API.
  7. Select Deployments > + Add deployment.
  8. Enter Catalog Gateway, select Workshop Testing as Environment, and select the v1 Catalog OpenAPI Definition.
  9. Set Runtime URL to the APIM Catalog base URL including /catalog, but not /products and not any credentials.
  10. Select Create.
Learn more: Environment and deployment fields.

Test and Verify

  1. Find Catalog API in the API Center asset list.
  2. Inspect v1, its Testing lifecycle, and the stored definition.
  3. Inspect Catalog Gateway and confirm its environment and definition references.
  4. Compare Runtime URL with the APIM Catalog API base URL.
  5. Use the published APIM developer portal from Lab 04 to call /products again with the product subscription.
  • The inventory contains one Catalog API and a v1 OpenAPI definition.
  • The deployment references the testing environment and correct definition.
  • The runtime URL includes the APIM API suffix and no secret.
  • API traffic still goes to APIM, not API Center.

Troubleshooting

SymptomCheck
Provider registration deniedAsk a subscription administrator to register Microsoft.ApiCenter; do not grant yourself broader access.
Region unavailableUse the current API Center region list and subscription policy, not an old slide's locations.
Definition rejectedUse the actual JSON exported in Lab 02; check it parses and says OpenAPI 3.0.x.
Deployment has wrong URLUse the gateway's Catalog base URL, not App Service, localhost, or the developer portal.
Inventory exists but calls failInventory is not runtime configuration. Diagnose APIM subscriptions and backend reachability independently.

Cleanup and References

Important: reserve the final 15 minutes for cleanup and recap. APIM, App Service plans, Function hosting/storage, and monitoring can continue to incur charges. Deleting a portal page or an API Center record does not delete its runtime.
  1. Stop local sample processes using Ctrl+C.
  2. In Resource groups, open your exact rg-apim-workshop-<suffix>.
  3. Inspect the resource list. Confirm every item belongs to this disposable workshop, including prework Function resources and the App Service plan.
  4. Select Delete resource group, enter the exact name, and confirm. Never delete a shared group.
  5. Wait for deletion to complete and verify the group is no longer listed. If deletion fails, inspect locks, permissions, and deployment activity rather than assuming costs stopped.
  6. Check for any workshop-only hosting plans, storage accounts, or monitoring resources created in a different group during prework. Delete only those exact workshop-owned resources after inspection.
  7. Remove exported credentials from local notes and clear the clipboard. Rotate any key accidentally disclosed while a shared resource remains in service.

If you used shared infrastructure, delete only your API Center records, imported APIM APIs/product/subscription, and accounts created for the lab with the resource owner's agreement. Do not delete shared services or groups.

  • Dedicated workshop resources are gone, or any intentionally retained resources and costs are documented.
  • No host keys or subscription keys are in source control.
  • No local sample process remains running unnecessarily.
