Azure API Management for Developers
Developer Workshop | Developers and architects | L300 | 4 hours

Build an API publishing and discovery experience using Azure API Management
and Azure API Center.

You will:
- Publish a .NET 10 Catalog API and an HTTP-triggered Azure Function.
- Apply and test gateway policies and subscription access.
- Publish an APIM developer portal and use a consumer subscription.
- Register an API contract and deployment in API Center.

Before the session:
- Review the lab catalog's prework and cost notice.
- Install Git, VS Code, PowerShell 7, .NET 10 SDK, and Azure CLI.
- Provision classic Developer-tier APIM and wait until it is ready.
- Prepare the HTTP Function using the documented Function prework.
- Confirm subscription permissions, allowed regions, and quotas.
- Use a dedicated disposable resource group and synthetic data only.

The four-hour schedule assumes prework is complete.
Azure resources can incur charges. Final cleanup is part of the workshop.

Created by Walid Amro (CSA at Microsoft).
