Describe what exists, where it runs, and which contract it implements without inserting another gateway into the request path.

Inventory Beyond One Gateway

Azure API Center maintains structured information about APIs across your organization. You can inventory APIs in design, APIs behind APIM, and APIs deployed elsewhere.

Inventory and metadata support discovery and governance. They do not automatically secure a backend, route traffic, or guarantee that a stored contract matches the running implementation.

Start Small, Keep Records Useful

Use a small metadata vocabulary with clear ownership. A manually registered record is useful only if someone maintains its lifecycle, definition, and deployment information when the API changes.

API Center offers Free and Standard plans. The required lab uses Free and manual registration; it does not depend on synchronization or a separate API Center portal deployment. Verify current limits and regional availability before provisioning.

Important: the documented API Center Standard-plan benefit for linked APIM instances lists Standard, Standard v2, Premium, and Premium v2. Do not assume the workshop's Developer tier qualifies.

Key takeaway

APIM governs calls. API Center helps govern the portfolio. A reliable API platform needs the right controls at both levels.
