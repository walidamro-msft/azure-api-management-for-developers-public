Detailed Training Guide

Anchor explanations in the request path, then require observable evidence before moving to the next lab.

Facilitation4-hour delivery

Preflight

Use the timed agenda and send the prework ahead of the session. Plan an independent clean-environment dry run; local code validation does not establish cloud quota, portal email, or region availability.

  • Confirm APIM is ready, not activating. If an attendee starts late, continue concepts while provisioning runs.
  • Keep a trainer demonstration fallback, clearly labeled as such. Do not share administrator or all-access keys.
  • Check the prepared Function App returns 200, uses Function authorization, and is visible in the intended subscription.
  • Know the cost and cleanup owner of every backend plan, storage account, and monitoring resource.

Pacing and Stretch Work

Keep identity-provider configuration, private networks, self-hosted gateway deployment, APIOps pipeline implementation, and separate API Center portal setup outside the required four-hour path. Their concepts are included in the reference sections; their deployment is not a hidden required lab. Do not add a sixth lab mid-session.

The GenAI extension is approximately 20 minutes of additional reference reading, not part of the 85-minute core concept allocation. Offer it as follow-up or schedule an explicit extension; do not require model, embeddings, or Redis deployment for the five labs.

For early finishers, ask them to explain a trace, compare version and revision choices, or identify what would need to change to block direct Catalog backend access. Keep extensions separate from the required success criteria. To teach every reference section live, schedule a longer session rather than shortening the five labs without approval.

If cloud delays consume the buffer, record the unmet checkpoint and arrange follow-up. A polished demonstration is useful, but it is not evidence that the attendee's resources work.

Close With Cleanup

  1. Reserve the final 15 minutes before taking extended questions.
  2. Walk the cleanup checklist and inspect the dedicated group's resource list.
  3. Check any Function support resources or App Service plans outside that group.
  4. Have attendees verify deletion completion, not just the notification that deletion started.
  5. Recap the difference between runtime policy, consumer onboarding, and portfolio inventory.
